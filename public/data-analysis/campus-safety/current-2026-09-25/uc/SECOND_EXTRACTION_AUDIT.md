# UC second computational extraction audit

Checked September 25, 2026. **Pass: all 2,856 source cells match exactly**, including values and missingness status: 2,660 numeric, 112 source N/A, and 84 omitted-column cells. No missing keys, extra keys, or duplicate keys. Coverage is 17 reporting campuses across nine UC institutions; Merced remains unverified and excluded.

This is a **second computational method by the same source reviewer**, not second-person review, agency authentication, or external peer review. The original extraction used pypdf text expressions and a manual Berkeley table transcription. `audit_second_extraction.py` independently reads original PDF bytes with pdfplumber/pdfminer, locates physical table grids, and assigns columns from the visually reviewed source headings. It does not import the first parser or read the original CSV until the alternate cell set is complete. Source hashes, software version, comparison results, and each removed superscript are recorded in `second_extraction_audit.json`; alternate cells are retained in `second_extraction_cells.json`.

Superscript digits are removed by their smaller source-PDF font size, rather than the first parser's keyed corrections. This separately confirms Davis's 86 with footnotes 1 and 2; Riverside's 389, 14, 11, 14, 8, 10, and 2 with their numeric note markers; and Santa Cruz's 38 and 16 with notes 6 and 7. Berkeley's defective character map requires a visually verified ten-digit glyph map. The second method reads original content-stream character order within table-cell bounds; a fresh rendered-page inspection confirms all 168 Berkeley cells, including fondling 17 and public-property stalking 2 in each year. Ordinary left-to-right glyph sorting would misread one overlapping glyph pair and was not used.

The five UCSF supplement tables were also compared with the full report's corresponding pages by the second engine: all 1,050 core-category and unfounded values agree. Unfounded counts are excluded from the four-geography dataset. UCLA's sexual-assault subtotal and Santa Barbara's hazing rows remain excluded from this fixed 14-category series; their constituent categories are not double counted.
