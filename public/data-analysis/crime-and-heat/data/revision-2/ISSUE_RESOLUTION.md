# Methodological revision: scope and issue resolution

24 September 2026. This document responds to methodological concerns about the initial release. Revised numerical results and the independently frozen sensitivity plan accompany it. A change in statistical significance is not a target of the revision. The original release remains available for comparison.

## Why a population offset does not automatically solve the problem

For fixed ZIP population P_z, a model with log(P_z) as an offset and an unrestricted ZIP intercept a_z has the same fitted values as a model with intercept a_z + log(P_z). Adding that fixed offset therefore cannot change the within-ZIP temperature coefficient. It can change how the intercept is expressed, not create missing daily exposure-population data. Resident population also does not measure commuters, visitors or the population covered by an incomplete administrative export. The study continues to estimate record counts per ZIP-day.

## Revision inference

The fixed plan contains eleven specifications for each of two outcomes, including the paired legacy-weather comparator. Ten linear temperature coefficients per outcome plus spline joint and nonlinearity tests form 24 tests, corrected together with Holm's method. Individual confidence intervals and spline pointwise bands remain nominal, not simultaneous. HAC14/28 comparisons are declared covariance diagnostics. The model battery and quota-driven sample amendment were frozen before computing revised estimates, after the original results and external feedback were known; this remains retrospective work. A separately documented numerical amendment computes the extended-MLE boundary for exactly certified seasonal zero rows after a diagnosed sparse-DV separation failure; it preserves positive events and the planned temperature hypotheses.

Original source files, published aggregates and prior numerical outputs are preserved. The revised interactive weather explorer uses civil-day values for the 64 fully acquired ZIPs; the full record explorer's totals and category definitions remain the same. The provider's daily acquisition limit prevented completion of 48 additional ZIPs. The available subset contains 98.5% of general and 98.0% of DV groups in the original eligible sample, but availability is not random. Original-versus-corrected weather comparisons use exactly the same acquired ZIPs. The full original reference remains distinct. A formal list of release files, hashes, sources and executable code accompanies the amended publication.
