METHODOLOGY / READ BEFORE RANKING

What this measures.

Observed performance in an explicitly limited historical sample. No index establishes who had the greatest underlying skill.

01

Counts before averages

KPR = summed kills ÷ summed rounds. DPR = summed deaths ÷ summed rounds. Net KPR = summed (kills − deaths) ÷ summed rounds. Longer maps contribute their actual rounds.

02

Comparable windows

Map windows use consecutive qualifying maps, bounded to 365 days. CS:GO and CS2 remain separate. Calendar windows use their actual observed sample; inspect the sample size.

03

Contemporary dominance

Relative scores compare equivalent aggregate windows against contemporaries available at the endpoint. Reference composition and small populations affect results.

04

An experimental index

PPI combines standardized components. KPR and Net KPR share kill production; changing the components tests this dependence. The index is descriptive, not a validated estimate of round-winning contribution.

05

History stays historical

A record appears only after its window completes. Retired players keep records. Active form expires after the documented inactivity threshold. Opponent estimates must use pre-match information.

06

The missing history matters

Coverage, region, role, team strength and career length affect observed maxima. Overlapping windows are dependent. Unrecorded performances cannot be ranked, and unknown values are never treated as zero.

Published rating versions are preserved as source observations; incompatible ratings are not treated as a common cross-era scale. See project methodology, source inventory and validation reports for full definitions.
