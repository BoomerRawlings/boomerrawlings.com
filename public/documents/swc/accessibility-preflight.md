# Accessibility preflight

Use this short check before delivering or publishing a document, page, slide deck, image, or video.

## Structure

- [ ] The title is clear and headings follow a logical order.
- [ ] Lists and tables use real list/table structure rather than spacing alone.
- [ ] Reading order still makes sense without the visual layout.

## Links and language

- [ ] Link text describes the destination; avoid repeated “click here” links.
- [ ] Instructions do not depend only on color, position, shape, or sound.
- [ ] Acronyms and specialized terms are explained when needed.

## Images and media

- [ ] Informative images have concise alternative text.
- [ ] Decorative images are marked decorative or have empty alt text.
- [ ] Video has accurate captions; audio-only content has a transcript.

## Documents and interaction

- [ ] Content works with keyboard-only navigation.
- [ ] Focus is visible and follows a sensible order.
- [ ] Text remains readable when zoomed.
- [ ] Exported PDFs have searchable text, tags, a title, and a set reading order.

## Final check

- [ ] Run the appropriate accessibility checker, then manually review anything it cannot judge.
- [ ] Ask the supervisor or accessibility support contact when the requirement is unclear.
