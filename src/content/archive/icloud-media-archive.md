This project brought 31,550 photos and videos out of iCloud and into a locally stored, structured collection.

The migration used staged batches, file checks, and promotion records to move the library without changing the cloud source or original media. The local result is organized for continued access and preservation.

A separate derived catalog adds searchable text and structured observations while keeping its outputs apart from the original files. Source references and processing provenance connect those derived records back to the archive.
