This project moved 31,550 photos and videos out of iCloud into an organized local media library.

The migration used staged batches, file checks, and promotion logs to move the library without changing the cloud source or original media. The local result is organized for continued access and preservation.

A separate searchable layer adds text and structured observations while keeping those outputs apart from the original files. Source references and processing provenance connect each result back to its source media.
